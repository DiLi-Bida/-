# 一维微分方程与偏微分方程数值实验

本项目使用 Python 实现若干一维常微分方程（ODE）和偏微分方程（PDE）的有限差分求解示例，主要用于理解：

- 显式、隐式与中心差分格式；
- 初始条件和边界条件的离散处理；
- CFL 条件与数值稳定性；
- 解析解、制造解和收敛率验证；
- 数值解与解析解的可视化比较。

当前内容以教学和方法验证为主，不是面向生产计算的通用求解器。

## 项目结构

| 文件 | 内容 | 主要输出 |
| --- | --- | --- |
| `decay_vc.py` | 使用 θ 格式求解变系数衰减方程 `u'=-a(t)u+b(t)` | 常数解、线性解和制造解测试；终端输出收敛率 |
| `finite difference.py` | 使用时间中心差分求解简谐振子 `u''+ω²u=0` | 数值解与解析解对比图 `finite_difference.png` |
| `linear_quadratic_solution.py` | 使用制造解验证受迫振子差分程序 | 对比图 `linear_quadratic_solution.png` |
| `diffu1D_u0.py` | 显式差分求解一维扩散方程 | 数值解与解析解的动态对比 |
| `wave_equation_1d_fixedEnd.py` | 中心差分求解固定端一维波动方程 | 数值解与驻波解析解的动态对比 |
| `wave_equation_1d_periodicEnd.py` | 周期边界条件下的一维波动方程探索 | 数值解与周期解析解的动态对比 |

## 运行方法

在本目录打开 PowerShell，然后执行相应脚本。

### 1. θ 格式及收敛率测试

```powershell
python .\decay_vc.py
```

程序依次执行：

1. 常数解析解测试；
2. 线性解析解测试；
3. 制造解收敛率测试。

对于 θ=0 和 θ=1，理论时间精度为一阶；对于 θ=0.5（Crank–Nicolson 格式），理论时间精度为二阶。程序通过逐次减半时间步长并计算误差，检查观测收敛率是否接近理论值。

### 2. 简谐振子

文件名包含空格，运行时需要加引号：

```powershell
python ".\finite difference.py"
```

也可以调整参数：

```powershell
python ".\finite difference.py" --I 1.0 --w 6.283185 --dt 0.02 --num_periods 5
```

参数含义：

- `--I`：初始位移；
- `--w`：角频率 ω；
- `--dt`：时间步长；
- `--num_periods`：模拟周期数。

### 3. 受迫振子制造解

```powershell
python .\linear_quadratic_solution.py
```

制造解取为

```text
u(t) = t² + 2t + 1
```

根据该解反推外源项，再比较数值解与解析解。这种做法适合检查离散公式、源项和第一时间层的实现是否正确。

### 4. 一维扩散方程

```powershell
python .\diffu1D_u0.py
```

求解的问题为

```text
u_t = a u_xx,
u(0,t) = u(L,t) = 0,
u(x,0) = sin(πx/L).
```

使用显式 FTCS 格式，稳定性参数为

```text
F = a Δt / Δx².
```

对于当前一维问题，通常要求 `F <= 1/2`。程序当前使用 `F=0.5`，位于理论稳定边界。

### 5. 固定端一维波动方程

```powershell
python .\wave_equation_1d_fixedEnd.py
```

求解的问题为

```text
u_tt = c²u_xx,
u(0,t) = u(L,t) = 0,
u(x,0) = A sin(πx/L),
u_t(x,0) = 0.
```

对应解析解为

```text
u(x,t) = A cos(πct/L) sin(πx/L).
```

空间和时间方向均采用二阶中心差分。CFL 数定义为

```text
λ = c Δt / Δx.
```

该显式格式通常要求 `λ <= 1`。当前默认参数 `c=1`、`Δt=0.01`、`Δx=0.01`，因此 `λ=1`。

### 6. 周期边界一维波动方程

```powershell
python .\wave_equation_1d_periodicEnd.py
```

脚本使用 `numpy.roll` 构造周期邻点，并与以下解析模态比较：

```text
u(x,t) = A cos(2πct/L) sin(2πx/L).
```

当前周期网格同时保留了 `x=0` 和 `x=L`，但时间推进只作用于内部数组。因此该脚本目前主要用于现有正弦初值的探索性演示；若要支持一般周期初值，建议改为不重复右端点的网格，即 `endpoint=False`，并在全部独立网格点上进行周期更新。

## 稳定性验证

稳定性验证关注的是：初值误差、截断误差和舍入误差是否会在时间推进中失控放大。

对于一维波动方程，可以固定空间步长，改变 CFL 数，例如：

```text
λ = 0.5, 0.9, 1.0, 1.05, 1.2
```

并进行足够长时间的计算，监测：

- `max(abs(u))` 是否持续增大；
- 数值解是否出现越来越强的高频振荡；
- 数值误差是否近似指数增长；
- 离散能量是否保持有界。

预期 `λ <= 1` 时解保持有界，而 `λ > 1` 时会出现数值不稳定。数值实验用于确认程序行为符合理论结果，不能代替 von Neumann 分析或离散能量法给出的稳定性证明。

## 网格收敛性验证

若有解析解，可在同一终止时刻计算误差：

```text
E_h = sqrt(Δx Σ_i (u_i^num - u_i^exact)²).
```

依次使用空间步长 `h`、`h/2`、`h/4`，并保持 CFL 数不变，即同步缩小 `Δt`。观测收敛阶为

```text
p = log(E_h / E_(h/2)) / log(2).
```

当前波动方程格式的空间和时间离散均为二阶。在解足够光滑、边界和第一时间层均正确实现，并且计算进入渐近收敛区间时，观测阶数应接近 2。

建议至少报告：

| Nx | Δx | Δt | CFL | L2 误差 | 最大误差 | 观测阶数 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 50 |  |  |  |  |  | — |
| 100 |  |  |  |  |  |  |
| 200 |  |  |  |  |  |  |
| 400 |  |  |  |  |  |  |

## 当前项目的验证状态

- `decay_vc.py` 已包含解析解/制造解测试和时间收敛率断言。
- 简谐振子和受迫振子脚本已提供数值解与解析解的图像比较。
- 扩散方程、固定端波动方程和周期波动方程已提供解析解对照。
- PDE 脚本尚未自动计算误差表、观测收敛阶和离散能量。
- 波动方程脚本尚未实现自动 CFL 参数扫描。

因此，目前结果能够进行直观正确性检查，但要形成完整的数值验证项目，还应补充自动化稳定性实验和网格收敛性测试。

## 已知限制

- 多数参数直接写在脚本末尾，尚未统一为命令行参数或配置文件。
- 多数脚本在导入时就会直接运行，不便于单元测试和复用。
- PDE 程序保存全部时间层；网格增大时内存占用会快速增加。
- 动画程序默认不保存结果，关闭窗口后需要重新运行。
- 部分源文件中的中文注释存在编码显示异常，建议统一转换为 UTF-8。
- 周期边界脚本需要重构网格端点处理后，才能作为一般性的周期求解器使用。

## 后续改进建议

1. 将模型参数改为命令行参数，并为所有脚本添加 `if __name__ == '__main__':` 入口。
2. 为扩散方程和波动方程加入 `L2`、`L∞` 误差及收敛阶计算。
3. 增加 CFL 参数扫描，绘制最大振幅或离散能量随时间变化的曲线。
4. 将周期网格改为不重复端点的表示方式。
5. 将求解、误差分析和绘图拆分成独立函数，便于测试和复用。
6. 增加自动测试，检查解析解误差、理论收敛阶和稳定条件。

完成这些改进后，本项目可以较完整地展示从方程离散、程序实现到稳定性与收敛性验证的数值计算流程。
